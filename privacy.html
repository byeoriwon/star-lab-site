개인정보처리방침

시행일: 2026년 10월 28일

스타랩(Star Lab)은 이용자의 개인정보를 존중하며, 공식 웹사이트에서 처리하는 정보와 문의 방법을 아래와 같이 안내합니다.

이 방침의 적용 범위

이 방침은 스타랩의 공식 소개 웹사이트에 적용됩니다. 개별 모바일 앱이나 소프트웨어에서 처리하는 정보는 해당 서비스의 별도 개인정보처리방침을 확인해 주세요.

1. 웹사이트 이용 시 처리하는 정보

이 웹사이트는 회원가입, 로그인, 결제 또는 개인정보 입력 양식을 제공하지 않습니다. 스타랩은 이 웹사이트에 광고 도구, 방문자 분석 도구, 추적 스크립트 또는 자체 쿠키를 사용하지 않습니다.

다만 웹사이트 호스팅 서비스인 GitHub Pages는 보안을 위해 방문자의 IP 주소를 기록하고 저장합니다. 호스팅 과정에서의 정보 처리에 관한 자세한 내용은 GitHub Pages의 데이터 수집 안내와 GitHub 개인정보처리방침에서 확인할 수 있습니다.

2. 이메일 문의 시 처리하는 정보와 목적

이용자가 문의 이메일을 보내는 경우 발신자의 이메일 주소, 이름(제공한 경우), 문의 내용 및 첨부파일 등 이용자가 직접 제공한 정보를 문의 확인과 답변, 관련 문제 해결을 위해 처리합니다.

문의에 필요하지 않은 주민등록번호, 비밀번호, 결제정보 등 민감한 정보는 보내지 마세요.

3. 보유 기간과 삭제

이메일 문의로 제공받은 개인정보는 문의 처리 목적이 달성되어 보관할 필요가 없어지면 지체 없이 삭제합니다. 관계 법령에 따라 보관해야 하는 정보는 해당 법령에서 정한 기간 동안 보관한 후 삭제합니다.

전자적 형태의 정보는 복구하기 어렵도록 삭제하며, 보관 중인 문의 정보는 업무상 필요한 범위에서만 접근합니다.

4. 외부 서비스와 제3자 제공

스타랩은 문의 정보를 판매하거나 광고 목적으로 제공하지 않습니다. 이용자의 동의가 있거나 법령에 근거가 있는 경우 외에는 제3자에게 제공하지 않습니다.

공식 문의 이메일은 Google의 Gmail을 사용합니다. 문의 메일은 이메일 송수신과 보관을 위해 Google 서비스 인프라에서 처리될 수 있습니다. 이메일 서비스 자체의 정보 처리에 대해서는 Google 개인정보처리방침을 참고해 주세요.

외부 링크를 통해 다른 서비스로 이동하면 해당 서비스의 개인정보처리방침이 적용됩니다.

5. 이용자의 권리와 행사 방법

이용자는 자신이 문의 과정에서 제공한 개인정보에 대해 열람, 정정, 삭제 또는 처리 정지를 요청할 수 있습니다. 아래 이메일로 요청해 주시면 본인 확인 등 필요한 절차를 거쳐 관계 법령에 따라 처리하겠습니다. 법령상 의무 등으로 요청 처리가 제한되는 경우에는 그 사유를 안내합니다.
